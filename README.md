# Сайт-приглашение: Анна і Євгеній

Готовый статический сайт: `index.html` + папка `assets/`. Никакой сборки не нужно.

## Что поменять перед отправкой гостям

Все данные лежат в одном месте — блок `CONFIG` в `index.html` (ищи строку `НАЛАШТУВАННЯ`):

| Поле | Что это |
|---|---|
| `date` | дата и время начала, формат `2027-06-19T15:30:00+03:00` (летом +03:00, зимой +02:00). От неё считаются календарь, обратный отсчёт, кнопка «Додати в календар» |
| `city` | город под датой на первом экране |
| `venue.name`, `venue.address` | ресторан и адрес. `venue.mapUrl` — ссылка из Google Maps (если пусто, карта ищет по адресу) |
| `timeline` | программа дня: время, название, подпись, иконка (`glasses`, `rings`, `dinner`, `cake`, `moon`) |
| `palette` | цвета дресс-кода |
| `rsvpDeadline` | до какого числа подтвердить присутствие |
| `contacts` | организатор: имя, телефон, Telegram (ник без @) |
| `music` | путь к mp3, например `assets/music.mp3` — появится кнопка музыки, включается при открытии конверта |

Тексты («Дорогі гості», детали про подарки и цветы, дресс-код) — прямо в HTML, их можно править как обычный текст.

## Как опубликовать (бесплатно)

Самый простой вариант — **Netlify Drop**: зайти на https://app.netlify.com/drop и перетащить папку `wedding-site` целиком. Через минуту будет ссылка, которую можно слать гостям.

Альтернативы: GitHub Pages, Vercel, Cloudflare Pages — подходит любой хостинг статических файлов.

## Ответы гостей (анкета)

Сейчас анкета без сервера: после заполнения гость видит свой ответ и кнопку «Надіслати в Telegram» — он сам пересылает его организатору.

Чтобы ответы автоматически падали в Google-таблицу:

1. Создать Google-таблицу → *Расширения → Apps Script*.
2. Вставить код и сохранить:

```js
function doPost(e) {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0];
  const p = e.parameter;
  sheet.appendRow([new Date(), p.name, p.attend, p.drinks, p.food, p.wish]);
  return ContentService.createTextOutput('ok');
}
```

3. *Начать развертывание → Новое развертывание → Веб-приложение*, доступ: «Все». Скопировать URL.
4. Вставить URL в `CONFIG.rsvpEndpoint`.

## Файлы

- `assets/envelope.webp` / `.jpg` — фото конверта (из присланного референса)
- `assets/seal.webp` / `.png` — сургучная печать, вырезанная с прозрачным фоном
- `assets/paper.webp` — текстура бумаги для карточек, сделана из того же фото конверта

## Шрифты

Great Vibes (каллиграфия), Cormorant Garamond (антиква), Montserrat (текст) — все три с полной поддержкой украинских букв Є, І, Ї, Ґ. Большинство «свадебных» скриптовых шрифтов кириллицы не имеют, поэтому буквы в именах подменялись другим шрифтом и выглядели неправильно.
